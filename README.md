# Descripción
Este código calcula el número de formas validas de interpretar una cadena compuesta por los caracteres 0, 1 y ?, donde ? puede representar tanto 0 como 1.

## Como funciona:
1- Ejecute el programa.

2- Ingrese una cadena compuesta únicamente por los caracteres 0, 1 y ?

finalmete el programa calculara y mostrará el resultado.

## Requisitos
Simplemente tener Python instalado.



(Matplotlib se usa solo para gráficar por eso el archivo grafico.py está diseñado para visualizar el comportamiento del algoritmo en terminos de tiempo de ejecución (ms) versus tamaños grandes de entrada. Este análisis ayuda a entender la complejidad del método implementado)
