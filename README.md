Descripción
Este código calcula el número de formas válidas de interpretar una cadena compuesta por los caracteres 0, 1 y ?, donde ? puede representar tanto 0 como 1.

Uso
Ejecute el script: python nombre_del_archivo.py

Ingrese una cadena compuesta únicamente por los caracteres 0, 1 y ?

El programa calculará y mostrará el resultado

Ejemplo
text
Ingrese la cadena s (compuesta solo por 0, 1 y ?): 1?0?
ans(s) = 6
Requisitos
Python 3.x

Matplotlib (solo para gráficos)

grafico.py
El archivo grafico.py está diseñado para visualizar el comportamiento del algoritmo en términos de tiempo de ejecución (ms) versus tamaños grandes de entrada. Este análisis ayuda a entender la complejidad computacional del método implementado.
